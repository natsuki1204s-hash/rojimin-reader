# ロジみん読み上げ

claude.ai で Claude の返信が出終わったら、VOICEVOX のキャラクターの声で自動的に読み上げる Tampermonkey スクリプトです。

## できること

- 返信の本文だけを読み上げる（コードブロック・表・作業表示・添付ファイル名・時刻表示は読まない）
- 1文目を先に合成して、すぐに喋り出す
- 画面右下のメニューからキャラ・スタイルを切り替える（選んだキャラは保存される）
- 話速・音高・抑揚・音量をスライダーで調整する（キャラごとに保存される）
- ON/OFF ボタン（状態は保存される）、Esc キーで今の読み上げだけ停止

## 必要なもの

- Chrome などのブラウザ（Claude デスクトップアプリでは動かない）
- Tampermonkey 拡張機能
- VOICEVOX（起動しておく。エンジンは `http://127.0.0.1:50021`）

## 入れ方

1. Tampermonkey の「新規スクリプトを追加」を開き、中身を全部消して `rojimin-reader.user.js` を貼り付けて保存
2. Chrome の拡張機能の管理 → Tampermonkey の「詳細」→「ユーザースクリプトを許可」をオン
3. VOICEVOX を起動してから claude.ai を開く（F5 で再読み込み）
4. 初回に通信の許可を聞かれたら「常に許可」

## 注意

- claude.ai の画面構成が変わると動かなくなることがあります。F12 → Console の `[ロジみん読み上げ]` の行が調査の手がかりになります
- 読み上げた音声を動画などに使う場合は、各キャラの規約に従ってクレジット（例: `VOICEVOX:東北きりたん`）を表記してください
